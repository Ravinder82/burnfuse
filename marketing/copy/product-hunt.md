## Maker's first comment

> I kept waking up to API bills I would have caught in a minute if anything had been
> watchful at 2 AM. Dashboards show you yesterday; alerts fire when a job has already run
> all night.
>
> So BurnFuse is a breaker, not a dashboard. It lives in the menu bar as one colour block.
> It reads the provider's own cost figure every minute — the key you already paste is the
> key it watches — and when a rate crosses what you set, it trips: menu bar red, a
> notification, an optional Slack/Discord webhook, and where the provider's API allows it
> (OpenAI, Anthropic admin keys), the trip offers to switch the key off, one more press.
>
> Two rules shaped everything: it only shows numbers it has actually measured ("no reading
> yet" instead of $0.00), and it is exact about what it cannot do — where a provider
> publishes no cost a key can read, the row says so and takes the number from you. Thirty
> providers, no dead ends.
>
> No account, no telemetry, no server. Keys live in one file on your Mac and go only to the
> provider you named. Native SwiftUI, MIT-licensed, macOS 14+. Feedback very welcome.
