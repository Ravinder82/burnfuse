## LinkedIn (needs your account)

> I kept waking up to AI API bills I would have caught in a minute if anything had been
> watching at 2 AM. Dashboards tell you yesterday. What I wanted was a breaker.
>
> So I built BurnFuse: a native macOS menu-bar app that is one colour block — green
> settled, amber climbing, red tripped, with the live burn rate inside. It reads the
> provider's own cost figure every minute (OpenAI, Anthropic, OpenRouter), trips a per-key
> cap inside a minute — menu bar, notification, Slack/Discord — and where the provider's
> API allows it, offers to switch the key off itself.
>
> Two design rules worth sharing: it never shows a number it hasn't measured, and it says
> plainly what it cannot do. Where a provider publishes no readable cost, the row names
> where the number lives and takes it from you.
>
> No account, no telemetry, no server. Keys stay in one file on your Mac. MIT-licensed.
>
> github.com/Ravinder82/burnfuse
>
> #macOS #AI #buildinpublic #opensource
