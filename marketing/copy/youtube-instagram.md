**Description:**

> BurnFuse is a macOS menu-bar spend breaker for AI API keys. One colour block: green
> settled, amber climbing, red tripped — the live burn rate is inside. When a key tripped a
> cap you set, you hear it inside a minute: menu bar, notification, Slack/Discord webhook —
> and at OpenAI and Anthropic, one more press switches the key off.
>
> It reads the provider's own cost figure every minute (OpenAI, Anthropic, OpenRouter, or
> your own endpoint). Where a provider publishes nothing a key can read, the row says so
> and takes the number from you — thirty providers by name, no dead ends. It never shows a
> number it has not measured.
>
> No account, no telemetry, no server. Keys live in ~/.burnfuse/keys.json, readable by you
> alone. Native SwiftUI, macOS 14+, MIT.
>
> Install: https://github.com/Ravinder82/burnfuse
