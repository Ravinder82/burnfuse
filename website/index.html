02 / where the number comes from

The key you already use is the key it watches.

Paste it once. BurnFuse pulls the provider’s own cost figure every minute — no scripts, no numbers typed by hand.

OpenAI · reads itself
Anthropic · reads itself
OpenRouter · reads itself

Where a provider publishes no cost figure a key can read, the row says so, names where the number lives, and takes it from you. Thirty providers. Not one dead end.

03 / inside a minute

From spike to stop.

A trip marks the key, logs the minute, and tells you — menu bar red, a notification, an optional Slack/Discord webhook — and where the provider allows it, offers to switch the key off itself. One more press.

menu bar red → notification →
Slack / Discord → switch off at OpenAI…

04 / your mac, not our server

No account.
No telemetry.
No server.

Keys live in one file, readable by you alone, and are sent only to the provider you named. No analytics, nothing proxied anywhere.
